Design Principles

🔌 API Layer

Axios instance configured with base URL from VITE_API_URL env var. No hardcoded localhost. All SQF endpoints in one file.

🧩 Context

FilterContext wraps the /quick-facts layout. Holds the loaded hierarchy tree, selected node, and selected date. Syncs code+date to URL params.

🎣 React Query Hooks

One hook per API call. Query keys include [selectedNode.code, selectedDate] so React Query auto-refetches when filter changes — mirrors the Angular BehaviorSubject pattern.

🏭 Pages vs Components

Pages are route-level: SummaryPage, DetailsPage. Components are reusable: MetricCard renders in both summary and details. Charts are wrapped Chart.js components.

☁️ GCP-ready

vite build outputs to dist/. In prod, all API calls go to /api (same origin, proxied by Cloud Run / App Engine). No CORS issues.

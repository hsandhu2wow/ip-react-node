Error Handling Strategy

No data for level
status: "error-NoDataForThisLevel" → card renders as hidden (not shown in grid)
Data not yet loaded
status: "error-NoDataFound" → show cut-off ETA time from getDataLoadETA
Generic error
Network/server error → show error card with support email. React Query retries 3× automatically.
Loading state
While React Query is fetching → show MetricCardSkeleton (CSS pulse animation) for each expected card position
Filter change
When node or date changes → React Query staleTime=0 so it always refetches. Previous data shown as "stale" during refetch (no flicker).

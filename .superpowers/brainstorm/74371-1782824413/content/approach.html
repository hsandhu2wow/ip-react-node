The Angular DSA app has these features that are missing from the React app. Which approach should we take?

Which component approach do you prefer?

A

Create separate SummaryCard & DetailsCard components Recommended

Replace the generic MetricCard with two purpose-built components matching the Angular app-sqf-summary-card and app-sqf-details-card exactly. Cleaner separation, easier to maintain, exact feature parity.

Pros

  • Matches Angular architecture
  • Each card does one thing well
  • Easier to add card-specific features later

Cons

  • More new files to create
B

Enhance the existing MetricCard with a variant prop

Add all features to the existing MetricCard component with variant="summary" and variant="details" props. Keeps one component, but grows it significantly.

Pros

  • Fewer new files

Cons

  • Component becomes very large
  • Mixed concerns
